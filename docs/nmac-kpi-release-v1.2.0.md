# NMAC KPI — Release v1.2.0

## Release note (what users see)

**Headline:** Referral KPI from ARDTS, updated call metrics, and nursing KPI cleanup

**Body:** The dashboard now includes a **Referral KPI** section with live data from ARDTS — monthly status counts, booking and completion rates, pipeline stages, and trend charts. **Call performance** KPIs now track total incoming, answered, and missed/abandoned calls instead of answer rate and inbound volume alone. **Nursing KPIs** no longer include Annuals Supported (Nursing). The reporting month defaults to the last completed month when you open the dashboard.

---

## Changelog

- **new** — Referral KPI section in the NMAC master KPI navigation
- **new** — Live ARDTS referral status counts by selected month
- **new** — Referral trend charts — sent by month, booked vs needs action, status breakdown
- **improved** — Call performance KPIs — Total Incoming, Answered, and Missed/Abandoned Calls
- **improved** — Referral KPI layout — month tabs, balanced status cards, and period summary
- **improved** — Removed Annuals Supported (Nursing) from Nursing KPIs
- **improved** — Default reporting month opens on the last completed month
